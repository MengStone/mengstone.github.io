# 世界观故事添加规则

## 背景
- 世界观页面为独立页 `world.html`，标题「故事」，由首页「世界观设定集」卡片跳转进入。
- 世界观是**跨游戏通用设定**，不服务于某一款具体游戏（《拉比的村子》只是其中一个游戏项目）。
- 内容形式：**纪传体故事**——城市、人物、事件、物品各自成篇的独立传记，**不是**编年体，**不是**百科式分类条目。
- 分类四类：人物 / 城市 / 事件 / 物品。

## 添加故事时必须做
1. 每篇故事创建独立 md 文件，放入 `world/` 对应分类子目录：
   - 人物 → `world/persons/`
   - 城市 → `world/cities/`
   - 事件 → `world/events/`
   - 物品 → `world/items/`
2. 文件名用英文（snake_case，如 `warrior-aina.md`）；标题、正文用中文。
3. 在 `world/world.json` 新增条目，字段固定：
   - `slug`：英文标识，与文件名对应
   - `title`：中文标题
   - `tags`：分类数组，如 `["人物"]`
   - `excerpt`：从原文提炼的一句话摘要（用于目录卡片）
   - `file`：相对路径，如 `world/persons/warrior-aina.md`
   - **不要**添加 `date` / 纪年等字段（已废弃）。
4. 排版规则（忠实原文，只做呈现层调整）：
   - 只做自然分段，不增删、不改写原文。
   - 关键独白 / 书信 / 碑文用 `> ` 引用块。
   - 篇章转折可用 `---` 分割线。
   - 可适度 `**加粗**` 强调短语。
   - **正文首个元素必须是普通段落**（不得以引用块 / 标题开头），否则首字下沉会落在错误元素上。
   - 正文内无需重复标题行（页面大标题由 world.json 的 title 提供）。
5. 完成后告知用户已创建的文件与条目，由用户自行刷新验证。

## 明确不要做
- 不派浏览器子代理（browser_use）做页面验证——由用户自行验证；仅在用户明确要求时才做。
- 不添加用户原文之外的内容（自定义小标题、注释、设定补充说明）。
- 不写任何说明文档、README 说明、测试工具（除非用户明确命令）。
- 不改动 `world.html` 的页面结构与样式（格式调整仅限 md 排版层面），除非用户另行要求。
- 不删除代码注释，除非注释对应代码块被整块删除。
- 不用中文命名任何文件 / 目录 / 方法。

## Token 节省约定
- 读写收敛：优先精确 Grep + 小范围 Read，避免整文件全量读取。
- 回复精简：少用长表格与展开说明。
- 批量处理：一次多篇故事时一次性完成，避免逐篇往返。
